# Contributing lyrics

Anyone can add or improve Nohay, Marsiya, Manqabat and related pieces by opening a pull request. There is no login or CMS — the GitHub repository is the catalogue.

## Quick start

1. Fork the repository and create a branch.
2. Copy [`content/lyrics/_template.json`](content/lyrics/_template.json) to a new file:

   ```text
   content/lyrics/<type>/<short-english-slug>.json
   ```

   Use folder names: `noha`, `marsiya`, `manqabat`, `soz`, `salam`, `ziyarat`, or `hadith-e-kisa`.  
   Prefer ASCII filenames (e.g. `akbar-tumhein.json`). Files whose names start with `_` are ignored by the library build.

3. Fill in at least `title`, `type`, and `structure` (Urdu misras). Roman Urdu, `media_urls`, personalities, and events are optional but welcome.
4. Run locally:

   ```bash
   npm run validate:lyrics
   npm run build:library
   npm run typecheck
   ```

5. Open a pull request. CI validates every lyric file and rebuilds `library.json`.

## Field reference

| Field | Required | Notes |
| --- | --- | --- |
| `title` | yes | Display title (usually Urdu) |
| `title_roman` | no | Roman Urdu title for the script toggle |
| `type` | yes | `Noha`, `Marsiya`, `Manqabat`, `Soz`, `Salam`, `Ziyarat`, or `Hadith-e-Kisa` |
| `structure` | yes | Ordered bands; each band has `band_type` (`matla`, `saani_matla`, or `stanza`) and `misras` (`urdu` + optional `roman`) |
| `astai_chorus` | no | Tip / Astai refrain (`urdu` + optional `roman` arrays) |
| `media_urls` | no | YouTube / TikTok / audio links (one or more) |
| `audio_url` | no | Legacy single media field; prefer `media_urls` |
| `personalities` | no | e.g. `Imam Hussain (AS)` — see `src/lib/taxonomy.ts` |
| `events` | no | e.g. `Day of Ashura` — see `src/lib/taxonomy.ts` |
| `poet_name` / `reciter_name` / `scale_pitch` | no | Free text |
| `id` | no | Stable UUID; omit to auto-hash from the title |

Do not hand-edit `content/library.json` — it is regenerated by `npm run build:library` (and again in CI).

Bulk phonetic Roman for missing lines can be refreshed with `npm run add:roman` (hand-tuned files are skipped). Prefer careful human transliteration in PRs when you can.

## Editing an existing piece

Find the file under `content/lyrics/`, edit it, regenerate the library, and open a PR. Prefer small, focused changes (one lyric or a clear set of related fixes).

## Code contributions

UI and tooling PRs are welcome. Keep the app **static** (no server auth or database):

- Favourites and the Majlis planner stay on-device (IndexedDB)
- Shared programmes use a URL hash (`/e#…`), not a backend
- Project Pages use `NEXT_PUBLIC_BASE_PATH` (e.g. `/azadari`) — see [README.md](README.md)
